# Spark Admin Dashboard

A simple admin dashboard built with Bootstrap 5, jQuery, and Sass, bundled using ParcelJS.

## Project Overview

Spark Admin Dashboard is a lightweight and customizable admin interface designed for web applications. Utilising modern web technologies like Bootstrap 5 for styling, jQuery for DOM manipulation, and Sass for CSS pre-processing, this dashboard offers an efficient solution for managing application data and user interfaces.

## Features

- **Responsive Design**: Built with Bootstrap 5 to ensure compatibility across all devices.
- **Modular CSS**: Utilises Sass for easy customization and maintenance of styles.
- **JavaScript Components**: Includes essential Bootstrap JavaScript components and jQuery for enhanced interactivity.
- **Efficient Bundling**: Uses ParcelJS for fast and hassle-free bundling of assets.
